# Gerenciador de Bases 1.7.0

- Novo visual claro, com navegação e opções de limpeza simplificadas.
- Limpeza de uma lista por vez, com resumo individual no log.
- Cruzamento automático de CNPJs e telefones entre listas do mesmo lote. A primeira ocorrência válida tem prioridade; CNPJ repetido remove a linha e telefone repetido remove apenas o contato.
- Ajuste obrigatório de telefones, com compactação dos contatos, remoção de números sujos e exclusão de linhas sem telefone.
- Blocklist obrigatória para todos os usuários, exceto Davi.
- Indicação de Modo cadência quando Auto Raiz estiver desligado.
- Limpeza de Colunas em React e TypeScript, com processamento em worker e limite de logs.
- Correções de conexão com o banco e do ciclo de encerramento.

## Instalação e acesso

O instalador público não inclui senhas, arquivos de ambiente ou licença de API. Na atualização de uma instalação existente, o instalador preserva a configuração anterior localmente para migração. Configurações já importadas são mantidas.

Em um computador novo, use **Importar acesso** na tela de login e selecione o arquivo fornecido pela empresa por canal privado. A configuração de conexão com o banco e a importação de licença de API continuam disponíveis.

As atualizações baixadas por esta versão são instaladas no encerramento normal do aplicativo.
